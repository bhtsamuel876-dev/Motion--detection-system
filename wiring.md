# Wiring Guide

| Component | Arduino |
|---|---|
| HC-SR04 VCC | 5V |
| HC-SR04 GND | GND |
| HC-SR04 TRIG | D7 |
| HC-SR04 ECHO | D8 |
| Red LED | D2 through 220 ohm resistor |
| Green LED | D3 through 220 ohm resistor |
| Blue LED | D4 through 220 ohm resistor |

Arduino serial communication uses 9600 baud.
