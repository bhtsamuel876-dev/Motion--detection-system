# KLIKU Cement Ltd Motion Sensing and Detection System

Arduino-based ultrasonic detection system for monitoring the company entrance.

## Technologies
- Arduino Uno
- HC-SR04
- Proteus
- PHP
- MySQL
- HTML/CSS

## LED rules
- Up to 20 cm: Red and Green LEDs operate.
- Up to 10 cm: Blue LED also operates.
- Red: 200 ms ON / 150 ms OFF.
- Green: 250 ms ON / 350 ms OFF.
- Blue: 300 ms ON / 450 ms OFF.

## Database
Database: Motion_db
Table: Motion_data

## Folders
- Arduino: Arduino source code
- Database: MySQL script
- PHP: Web interface and API
- Documentation: Wiring, flowchart and verification notes
